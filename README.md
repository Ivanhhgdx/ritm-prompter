# Ритм

Браузерный суфлёр с плавной прокруткой вслед за речью.

**Сайт:** https://ivanhhgdx.github.io/ritm-prompter/

## Возможности

- Распознавание русской речи через Web Speech API браузера.
- Детерминированное сопоставление со сценарием, включая повтор предыдущих фраз, числа и небольшие ошибки распознавания.
- Плавное движение между результатами распознавания с ограниченным опережением; замедление и остановка на паузах.
- Переход через пустой отступ после завершения абзаца.
- Редактор с локальным сохранением текста, размер шрифта и центральная полоса фокуса.
- Портретная и горизонтальная компоновка телефона, безопасные отступы для iPhone.
- Полный экран с разворачиванием внутри окна, если браузер не поддерживает Fullscreen API.
- На паузе можно прокрутить сценарий назад или вперёд и поставить нужную строку у центральной полоски. «Продолжить» начинает с первого слова выбранной строки, сохраняя её положение до следующего результата распознавания.
- Пауза, возврат к началу, таймер и прогресс. Пробел — запуск/пауза, стрелки — смена позиции.

## iPhone: запуск без панелей Safari

Обычная вкладка Safari на iPhone может не разрешать полноэкранный режим для страницы. В этом случае кнопка показывает инструкцию, а не выдаёт разворачивание внутри вкладки за скрытие панелей браузера.

1. Откройте сайт в Safari и нажмите «Поделиться» (или «Ещё» → «Поделиться»).
2. Выберите «На экран “Домой”».
3. Включите «Открыть как веб-приложение», если этот переключатель есть, и нажмите «Добавить».
4. Запускайте с нового значка «Ритм». Кнопка полного экрана внутри приложения раскрывает область чтения; вкладок и адресной строки Safari нет.

Добавлены Web App Manifest, Apple web-app metadata и иконки. Ориентация не заблокирована: доступны портретное и горизонтальное положения. Это не обещание офлайн-распознавания; системные индикаторы iPhone могут оставаться видимыми. Доступ к речи в установленном веб-приложении зависит от версии iOS и проверяется после нажатия «Начать чтение».

[Инструкция Apple](https://support.apple.com/ru-ru/guide/iphone/iphea86e5236/ios)

## Микрофон и конфиденциальность

Откройте сайт по HTTPS, нажмите «Начать чтение» и разрешите микрофон. В Safari может требоваться включённая Siri или диктовка. Возможности и доступность службы распознавания зависят от браузера, региона и системных настроек.

Само приложение не записывает аудио и не отправляет его на собственный сервер. **Служба распознавания браузера может передавать звук на серверы поставщика и требовать интернет.** Если браузер сообщает об уже установленном локальном языковом пакете, приложение использует распознавание на устройстве. Большие модели не загружаются приложением. Сопоставление со сценарием выполняется локально без LLM и API-ключей. Текст сохраняется в localStorage на данном устройстве.

Распознавание не гарантирует идеальную точность. Плавная прокрутка сглаживает задержку результатов, но не устраняет задержку самой службы. Визуальный прогноз ограничен; непрочитанные слова не считаются прочитанными автоматически.

## Разработка

Node.js 22.13+ (для встроенного запуска TypeScript-тестов используйте Node 22.18+ или 24+).

```sh
npm ci
npm run dev:pages
```

Статическая сборка для GitHub Pages:

```sh
npm run typecheck
npm test
npm run build:pages
```

Результат находится в `dist/pages/`; это HTML, CSS и JavaScript без серверной части. Относительные пути позволяют размещать сборку в подпапке репозитория. GitHub Pages публикует содержимое ветки `gh-pages`, исходники находятся в `main`. Файл `.nojekyll` отключает преобразование статических файлов Jekyll.

Сохранён также первоначальный режим разработки Vinext (`npm run dev`, `npm run build`); он использует тот же компонент приложения. Для GitHub Pages используется `vite.pages.config.ts`, не требующий Cloudflare или Sites.

## Основные файлы

- `app/page.tsx` — интерфейс и редактор.
- `app/globals.css` — стили и адаптация.
- `hooks/use-prompter.ts` — жизненный цикл распознавания и чтения.
- `hooks/use-reading-motion.ts` — позиции строк и анимация.
- `lib/alignment.ts` — сопоставление слов.
- `lib/reading-motion.ts` — сглаживание и ограничение прогноза.
- `tests/` — проверки алгоритмов без микрофона.
